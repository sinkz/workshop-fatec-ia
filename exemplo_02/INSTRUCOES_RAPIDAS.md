# ⚡ Instruções Rápidas - 2 Minutos

## 🚀 Iniciar o Sistema

### 1. Backend (Terminal 1)

```bash
cd backend
npm install
node server.js
```

### 2. Frontend

1. Edite `frontend/config.js`
2. Cole seu token Groq (https://console.groq.com/)
3. Duplo clique em `frontend/index.html`

---

## 🧪 Testar

No chat, digite:

```
Liste os produtos
```

Depois:

```
Crie um produto chamado Webcam por R$ 200 na categoria Periféricos
```

O produto deve aparecer na lista à esquerda!

---

## 📝 Arquivos para Configurar

- `frontend/config.js` → Token Groq
- `backend/produtos-mock.js` → Produtos iniciais
- `mcp-server/config.js` → Ferramentas MCP
